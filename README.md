# Task Manager

A simple and responsive Task Manager Web Application built using HTML, CSS, and JavaScript.

## Live Demo

🚀 **Live Website:** https://debarghyasarkar-alt.github.io/Minorproject2/

## Features

- Add new tasks
- Display task list
- Mark tasks as completed
- Delete tasks
- Dynamic DOM manipulation
- No page reload required
- Clean and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How It Works

1. Enter a task in the input field.
2. Click **Add Task** to add it to the list.
3. Click **Complete** to mark a task as completed.
4. Click **Delete** to remove a task from the list.
